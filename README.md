# I2C_MemoryMap ツール

Saleaeのロジックアナライザ(Locig 2アプリ)で取得したI2C通信ログ(CSV)を読み込み、I2Cデバイス毎のレジスタ空間（Write / Read別）の遷移をImGui上のメモリビューアで視覚的に解析・再生するためのツールです。

---

## 📁 フォルダ構成

配布パッケージ内には以下のファイルが含まれています。

* **`i2c_memorymap.exe`** : メインプログラム
* **`devices.json`** : デバイス定義ファイル（ユーザー設定）
* **`sample_CSV/`** : サンプルデータ置き場

---

## 使い方
## 1. I2Cログファイル取得
Logic 2アプリからI2CログのCSVファイルを出力します。出力時の設定は以下に合わせてください。
* **`Columns`**: All
* **`Data`**: 任意
* **`Export Format`**: CSV
* **`User ISO8601 Timestamps`**: 使用しない
※確認時点のLogic 2アプリバージョン 2.4.46

## 2. デバイス設定 (`devices.json`)
exeファイルと同じ階層にある `devices.json` をテキストエディタで編集し、解析対象のI2Cデバイスを定義します。
デフォルトではサンプル用のデバイス定義が入っています。

* **`name`**: デバイスの表示名（ウィンドウタイトルに反映されます）
* **`address`**: 7ビットI2Cアドレス（16進数文字列、例: `"0x40"`）
* **`addr_width`**: アドレス幅（バイト数）
**デバイス登録上限**: `devices.json`に記述できるデバイス数に制限はありませんが、ログを表示できるデバイスは**最大3台まで**です。CSVファイルに出てきたデバイスアドレスの先着3台までが表示対象となり、4台目以降は無視されます。
---

## 3. 起動とCSVファイル選択

1. **`i2c_memorymap.exe`** をダブルクリックして起動します。
2. 起動直後にファイル選択ダイアログが開くため、解析したい **I2CログのCSVファイル** を選択します。
サンプルのCSVは`sample_CSV`フォルダにあります。
3. ウィンドウが立ち上がり、タイムライン操作や各デバイスのWrite/Readメモリマップの確認が行えるようになります。

---

## 4. 操作方法

* **タイムライン移動**: 画面下部のコントロールパネルにあるスライダー、または `<< Prev` / `Next >>` ボタンでタイムスタンプ単位のステップ移動が可能です。
* **キーボード操作**: キーボードの **← / → 矢印キー** でも前後のデータにすばやく移動できます。
